# 도랏이 (Dorati) v1.9

사람들이 가르친 말을 **실시간 공용 DB**에 저장해 모두가 같이 쓰는, SimSimi 스타일 한국어 챗봇.

- 라이브: <https://ageofwar-kr.github.io/dorati/>
- 저장소: `ageofwar-kr/dorati` (GitHub Pages)

## 화면
- 사용자: <https://ageofwar-kr.github.io/dorati/>
- 모션 (v1.9): 모드 버튼의 선택 표시가 미끄러지는 판(glider) 하나로 움직이고, 새로 오가는 말풍선만 iMessage처럼 살짝 튀어오른다(복원된 옛 대화는 제자리). 버튼은 누를 때 살짝 줄어들고, 이스터에그 끄기 필은 부드럽게 내려온다. 모두 `cubic-bezier(.22,1,.36,1)` 스프링 이징이고 `prefers-reduced-motion: reduce`에서 꺼진다.
- 관리자: <https://ageofwar-kr.github.io/dorati/admin.html> — 패스코드로 잠겨 있고, 사용자 화면에는 링크를 두지 않는다.
  - **사람 학습** 탭: Firebase `/pairs`(대화로 가르친 말) 검색·모드필터·정렬·수정·삭제
  - **기본 내장** 탭: `js/kb-corpus.js`의 내장 의도/Q&A 쌍 열람(읽기 전용, 검색·모드필터)

## 내장 대화 (v1.8)
- `js/kb-corpus.js`에 **의도 365개 + Q&A 쌍 46개**, 모드별 답변 총 **4,315개**.
- 일반 모드는 장난치는 반말·커뮤 말투·음슴체 58줄을 추가로 보강했다.
- 그중 **도랏 계열 답변 1,860개**(코퍼스 1,791 + 대화코어 69). 19금 태그가 붙은 문장을 뺄 순한 고정 풀은 **1,689개**.
- 도랏 답변은 실제 한국어 욕설(시발·존나·ㅅㅂ·ㅈㄹ·병신·개소리·꺼져·닥쳐·뒤져 등)과 커뮤 말투·음슴체로 다시 썼고, 성인(19금) 인텐트 5개(19금·키스·침대·몸매·밤 얘기)를 새로 넣었다.
- 모든 항목이 **모드마다 3개 이상의 서로 다른 답변**을 가진다(같은 말을 반복해도 답이 겹치지 않도록 최근 답변 회피).
- 주제: 인사·리액션, 감정, 학교·직장, 음식, 게임·미디어, 연애·관계, 생활, 인터넷 밈(킹받·중꺾마·럭키비키·어쩔티비·국룰·스불재 등), 커뮤니티 드립(어그로·분탕·떡밥·고인물·뉴비·가불기·실화냐·이왜진·ㅈㄱㄴ·스압·오운완·내돈내산·파묘 등), 요즘 밈(테토남·에겐남·원영적 사고·한강 고양이·이븐하게·나야 들기름·삐끼삐끼·마라탕후루·밤양갱·추구미·가나디·칠가이·줴줴이야), 생각·잡담.
- 문장 패턴 엔진: `A vs B`/`A 아니면 B` 선택, `~할까?` 결정, 왜/언제/어디/누구/몇/어떻게, `~냐?/~지?` 예·아니오, 가위바위보·숫자·운세·점수.
- 매칭 순서: 학습된 말 → 내장 Q&A 정확 일치 → 선택 패턴 → 문자 인덱스로 좁힌 의도 정규식 → 의문사/결정 패턴 → 사전(빠른 조회) → dice 유사도 → 되묻기.
- 모르는 말은 **가르칠 만한 문장(3자 이상)** 일 때만 "가르쳐줘"라고 묻고, 짧은 소리·자모는 재치 있게 받아친다.

### 똑똑이 모드 (v1.6)
- 구글 **Apps Script 웹 앱**을 얇은 중계 서버로 두고 **Gemini API**(무료 등급)로 답한다.
  - `gemini-3.5-flash-lite`를 기본 모델로 명시해서 보낸다(v1.9.1~). 앱이 `model`을 지정하지 않으면 중계 서버가 `gemini-3.8-flash`를 먼저 시도하다가 429/503로 수십 초를 버리거나 멈췄다. 빠른 이 모델을 먼저 쓰므로 보통 2~3초에 답한다.
  - **속도 (v1.9.2)**: 중계 서버의 `PRIMARY_MODEL`도 `gemini-3.5-flash-lite`로 바꿔, 모델을 지정하지 않는 옛 캐시 클라이언트도 느린 모델을 먼저 기다리지 않는다. 채팅 `maxOutputTokens`는 400, 문맥은 최근 4턴(8메시지)×200자로 줄였다.
    - 실측(원격 브라우저 실기기 채팅, 같은 질문 3~5턴): v1.9.1 3,575·2,611·3,337ms(평균 3,174ms) → v1.9.2 2,263·2,687·2,808·2,500·2,720ms(평균 2,596ms). **첫 답 3,575 → 2,263ms(−37%), 평균 −18%**.
    - 남은 병목은 Apps Script 자체다. 모델을 안 부르는 GET 한 번도 웜 1.1s·콜드 3.6s가 걸리고, 답변 길이에 따라 100자당 약 0.5초가 붙는다. 그래서 2.0~2.8초가 사실상 하한이다.
  - **사전 예열(pre-warm)**: 똑똑이 모드로 들어오거나 그 모드에서 입력을 시작하면 `Smart.warm()`이 중계 서버를 미리 깨운다(2분 스로틀). Apps Script 콜드 스타트 1~3초를 사용자가 타이핑하는 동안 끝내 첫 답이 빨라진다. `index.html`은 `script.google.com`·`script.googleusercontent.com`에 preconnect/dns-prefetch를 걸어 첫 요청의 DNS·TLS 지연도 없앴다.
  - `thinkingConfig`는 쓰지 않는다. `gemini-3.5-flash-lite`는 기본 `thinking_level`이 `minimal`이며 `thinkingBudget: 0`을 보내면 400으로 거부한다(3.8-flash는 반대).
  - 최근 4턴 문맥 유지, 닉네임을 자연스럽게 한 번 부르되 `아/야/님`은 붙이지 않음.
  - 제미나이 쪽 안전필터는 `BLOCK_ONLY_HIGH`(밈·놀림이 과검열되지 않게), 거부되면 설정 없이 재시도.
- **API 키는 Apps Script의 Script Properties(`GEMINI_API_KEY`)에만** 있고 저장소·웹소스에는 없다.
- 응답 전에 항상 **로컬 하드 필터**(자살·자해 109 안내, 범죄, 개인정보)를 먼저 돌려 API로 보내지 않는다.
- 중계가 실패·한도초과면 **내장 엔진 답변으로 조용히 폴백**해 채팅이 끊기지 않는다.
- 똑똑이 모드일 때 모드 버튼 위에 실제 사용한 모델명이 아주 작게 표시된다.

## 안전 (모든 모드 공통 최우선)
- **자살·자해**: 응답을 만들기 전에 차단하고, 109(자살예방 상담전화)·112·119 안내 문구로만 답한다. 학습 저장도 거부.
- **심각한 범죄·불법**: 차단 + 정중한 거절. 학습 저장 거부.
- **개인정보(주민번호·전화번호·계좌 등)**: 입력 즉시 경고, 저장 안 함.
- 욕설은 위 표대로 모드별 처리(하드 필터와 별개).

### 미친도랏은 이스터에그다 (v1.9)
- **미친도랏 버튼은 없다.** 화면 어디에도 없고, 19금 경고 모달도 없다.
- `도랏`을 누르면 그냥 **도랏** 모드로 들어간다(헤더 아래 하위 선택줄 없음). 다른 모드에서 눌러도 같다.
- 채팅창에 **`미친도랏이커몬`** 또는 **`미친도랏모드`** 를 치면 이스터에그가 발동한다(띄어쓰기가 어디로 가든 상관없다: `미친 도랏 이 커몬`, `미친 도랏 모드` 둘 다 발동).
  - 어떤 모드에 있던 바로 도랏 + 미친도랏으로 전환되고, 크림슨 테마가 적용되며, 채팅에 `🔞 이스터에그 발동 · 미친도랏 입장 완료` 배너와 매운 인사말이 뜨다.
  - 주문 문장은 엔진·자동학습을 거치지 않으므로 **공용 DB `/pairs`에 남지 않는다**.
- 미친도랏이 켜져 있는 동안에만 헤더 아래에 **`🔞 미친도랏 끄기 · 도랏으로`** 필이 조용히 나타난다. 누르면 도랏으로 돌아오고 필은 다시 사라진다.
- 미친도랏 상태는 저장하지 않는다(새로 고치면 언제나 도랏부터). 대화창에 `미친도랏`이라는 말만 치면 모드를 켜지 않고 엉뚱한 힌트만 준다.
- **도랏**: 쌘욕·팩폭·커뮤 말투·음슴체만. 남녀·밤·몸 이야기로 분류된 문장은 엔진이 자동으로 걸러내고, 19금 인텐트가 들어오면 "그 주제는 옆집 미친도랏에서만 한다"로 받아친다.
- **미친도랏**: 성인끼리 주고받는 19금 농담까지 전부. 미성년자·비동의·범죄·자해·혐오는 두 갈래 모두 하드 필터로 막는다.
- 두 갈래 모두 학습 DB는 기존 `/pairs`의 `dorat` 태그를 그대로 쓴다(스키마 변경 없음).

## 닉네임 · 대화 저장
- 첫 방문 시 **닉네임 게이트**가 뜬다(기본값 없음, 2자 이상 입력해야 시작).
- 닉네임과 대화 기록은 **이 기기 localStorage에만** 저장된다(서버 전송 없음).
- 헤더 `⋯` 메뉴에서 닉네임 변경 · 대화 내보내기(.txt) · 대화 지우기.
- **호칭 (v1.9.6)**: 건전·일반·똑똑이 모드는 닉네임 뒤에 `님`을 붙여 부른다(`원재님, 어 왔어 ㅋㅋ`). 이미 `님`으로 끝나는 닉네임은 겹치지 않는다. **도랏·미친도랏 모드는 `님`을 붙이지 않고 반말로 부른다**(`원재야, 어 왔어 ㅋㅋ`) — 받침이 있으면 `아`, 없으면 `야`를 붙인다(`김갑철아`, `자비스야`). 판단은 `Engine.nickCall(nick, mode)` 한 곳에서 하고, 대사·첫인사·헤더 배지·이스터에그 인사·대화 내보내기가 모두 이 함수를 쓴다. (v1.7~v1.9.5는 모든 모드가 `님`이었다.)

## 자동 학습
- 대화 턴이 끝나면 `(도랏이 말 → 사용자 답)`을 자동으로 공용 DB에 저장한다.
- 도랏이가 모르는 말에는 "그게 무슨 말이야? 어떻게 대답해야 돼?"라고 되묻고, **다음 사용자 발화를 그 말의 답**으로 학습한다.
- **모든 모드가 하나의 학습 풀을 공유**한다. 모드 차이는 출력 필터에서만 생긴다
  (건전=욕설 전면 마스킹, 일반=강한 욕만 완화, 도랏=그대로).
- 저장된 말은 다른 사용자에게 즉시(실시간 스트림) 또는 최대 45초 안에(폴링) 보인다.
- 👍/👎 로 답변 품질을 조정한다(가중 랜덤, 👎 3회 누적 시 숨김).

## 사전
- **국립국어원 표준국어대사전 OpenAPI** 사용(2026-11-17 발급 키, 하루 5만 회).
- CORS 헤더가 없어 브라우저에서 직접 호출할 수 없으므로,
  1. 공식 API에서 미리 받아둔 **내장 번들**(`data/dict/*.json`, 단어 700+·속담/관용구 1,000+),
  2. 공용 DB 캐시(`/dict/{단어}`),
  3. 중계 워커(설정 `dictProxy`) 또는 공용 DB 요청 큐(`/dictreq` → 워커가 응답) 순서로 조회한다.

| `atk_solo` | 608 | 단일 욕설("시발", "병신아", "닥쳐"…) — 던진 단어를 그대로 되받아친다 |
| `atk_final` | 1,183 | 최후 반격 — 문맥 없이 단독으로 날려도 통하는 대사 |

### 감지 순서 (`engine.js` → `detectAttack`)
1. 하드 안전 필터(자살·자해 / 범죄 / 개인정보) — 모든 모드 최우선, 그대로 유지.
2. 단일 욕설 — 한 단어만 던져도 `atk_solo`로 즉시 받아친다.
3. 점수 판정: 직접 비하어 3점 + 상황 욕설 2점 + 2인칭 1점. **3점 이상**이면 공격으로 본다.
4. 길이 40자 이상이면 `atk_long`, 아니면 카테고리(약올리기 → 외모 → AI → 반박 → 욕설 → 닥쳐 → 멍청 → 미친 → 찐따) 순.
5. 도랏 계열은 확률로 말투를 섞는다 — 약올리기 26%, 충청도·경기도·전라도·서울 각 10%.
6. 어디에도 안 걸리면 `atk_final`. 그래도 아니면 기존 학습/되묻기 흐름(가르치기는 유지).

- 공격 답변은 `kind:"attack"`으로 표시해 **공용 DB 학습에서 제외**한다(욕설 문답이 쌓이지 않게).
- 건전 모드는 공격어에도 정중한 답(4개), 일반 모드는 강한 욕설 없는 깝침(4개)을 쓴다.
- "관종이 뭐야" 같은 단어 질문은 공격으로 보지 않는다(2인칭이 없으면 사전·가르치기로).
- 안전선: 자살·자해, 범죄·불법, 성적 표현, 미성년자, 정치·지역·성별·장애 혐오, 실존 인물, 개인정보 0건.
  생성기 `tools/gen_attack.py`가 저장 전에 금지어를 정규식으로 검사하고, 걸리면 파일을 만들지 않는다.

## v1.9.6 — 도랏·미친도랏 호칭에서 '님' 제거
도랏 모드는 깝치는 반말 모드인데 닉네임만 `자비스님`으로 존대해 어긋났다.

- 호칭 판단을 `Engine.nickCall(nick, mode)` 한 곳으로 모았다.
  - `clean` · `normal` · `smart`(똑똑이): 기존대로 `자비스님` (이미 `님`이면 겹치지 않음).
  - `dorat` · `dorat_pure` · `dorat_crazy`: `님` 없이 반말로 `자비스야` — 받침이 있으면 `아`, 없으면 `야`(`김갑철아`).
    닉네임을 `자비스님`으로 정한 사람도 `자비스야`로 부른다. 한글 이름이 아니면(`Bob`) 이름만 부른다.
- 적용 지점: 첫 인사(`greet`) · 도랏 진입 인사 · 미친도랏 이스터에그 인사 · 답변 개인화(`personalize`, 22%) · 헤더 배지 · 대화 내보내기.
  헤더 배지는 모드를 바꿀 때마다 다시 그린다(`renderNickBadge`).
- 게이트 문구에 "도랏 모드에선 '님' 빼고 반말로 이름만 부른다" 추가.
- 검사: `tools/test_v195.py` 8) 닉네임 호칭 · `tools/live_v196.py`(라이브 3개 모드 대조).
